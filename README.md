# PumpkinChase

PumpkinChase is a Roblox script that teleports players to each pumpkin in the EventPumpkins folder, creating an engaging chase experience. This script is perfect for Halloween events, pumpkin hunts, or any game that requires players to interact with pumpkins.

## Install

1. Download the `PumpkinChase` script from the GitHub repository.
2. Place the script in the `StarterGui` folder of your Roblox game.
3. Ensure you have a folder named `EventPumpkins` in your workspace, containing the pumpkins you want to teleport to.

## Use

1. Run the game.
2. Click the 'RUN PUMPKINS' button to start the teleportation process.
3. Players will be teleported to each pumpkin in the `EventPumpkins` folder every 2 seconds.
